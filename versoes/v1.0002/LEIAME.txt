--------------------------------------------------------------------------------
 OBJETIVO
--------------------------------------------------------------------------------
Transformar o painel admin em um sistema gerencial de e-commerce para venda
  de materiais teológicos (e-books, apostilas, cursos). Novo módulo Venda (mini-PDV),
  gestão de Produtos com CRUD completo, Relatório com exportação CSV e
  Configurações (site + comerciais). Arquitetura MODULAR (um arquivo por módulo)
  adotando o MODELO JILO: topbar + abas data-tab + bottom-nav mobile + aba admin
  dedicada. A vitrine pública de vendas vive na RAIZ (index.html), separada do painel.

--------------------------------------------------------------------------------
  ESTRUTURA (um arquivo por módulo — MODELO JILO: abas data-tab)
 --------------------------------------------------------------------------------
  configuracoes.html     : Shell (topbar + abas data-tab + bottom-nav mobile + login)
  css/admin.css          : Estilos globais + responsivo (paleta navy/dourado/creme)
  js/config.js           : Constantes globais (URL, key, categorias, métodos, status)
  js/supabase.js         : Cliente REST + sessão segura (sem senha) + helpers CRUD

  Abas: dashboard, venda, produtos, relatorio, configuracoes + admin (oculta).
  Cada módulo expõe window.KerigmaModule_<nome> com mount(content, helpers).
  O router injeta os helpers ($, $$, toast, confirmBox, formatMoney, ...).

--------------------------------------------------------------------------------
 MÓDULOS / FUNCIONALIDADES
--------------------------------------------------------------------------------
 1. DASHBOARD
  - KPIs: produtos ativos, vendas hoje, receita do mês, ticket médio, pedidos pendentes.
  - Últimas vendas (tabela), produtos mais vendidos (ranking) e ações rápidas.

 2. VENDA (mini-PDV)
  - Busca/categoria de produtos ativos → clique adiciona ao carrinho.
  - Carrinho lateral (gaveta) com quantidade, desconto e taxa de cartão.
  - Cliente: nome, WhatsApp, email.
  - Pagamento: pix, dinheiro, cartão (taxa vai para o cliente — 3,49%), link, whatsapp.
  - Finalizar → grava sale + sale_items → recibo (copiar / enviar por WhatsApp).

 3. PRODUTOS
  - CRUD completo: criar, editar, duplicar, ativar/desativar, destaque, ordenar.
  - Filtros (busca, categoria, status) e preview do card em tempo real.
  - EXCLUSÃO PARAMETRIZADA (ver Configurações → allow_hard_delete):
    * Sem vendas vinculadas → pode excluir definitivamente.
    * Com vendas vinculadas + allow_hard_delete=OFF → só desativa (preserva relatório).
    * Com vendas vinculadas + allow_hard_delete=ON → exclui em cascata (avisa risco).

 4. RELATÓRIO
  - Filtros por período, forma de pagamento e status.
  - Totais: nº pedidos, receita (pagos), ticket médio, distribuição por pagamento.
  - Lista detalhada de vendas + exportação em CSV (UTF-8 BOM p/ Excel).

5. CONFIGURAÇÕES
   - Site (público): nome, subtítulo, WhatsApp, email, CTA, endereço, mensagem WA.
   - Comerciais: moeda (BRL/USD), forma de pagamento padrão,
     status padrão e ALLOW_HARD_DELETE (exclusão definitiva de produto com vendas).

  6. ADMIN (aba dedicada, modelo Jilo)
   - Login com as credenciais do painel (Supabase, role=admin).
   - Exportar produtos/vendas em CSV e backup completo em JSON.
   - Importar produtos a partir de JSON de backup.
   - Gerenciar categorias de produto (adicionar/remover).
   - Sessão e manutenção (recarregar, limpar localStorage).
   NOTA: categorias/preferências são mantidas em memória (window.APP_CONFIG);
         para persistência entre sessões, edite js/config.js.
